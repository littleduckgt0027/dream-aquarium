# Asset provenance

All fish, eyes, patterns, fins, tails, plants, rocks, light rays, bubbles, UI marks and the app icon were procedurally drawn or authored for this repository. Rendering source: frontend/src/Aquarium.jsx. App icon: frontend/public/icon.svg. No purchased images, generated asset service, third-party texture, or remote font is used. System fonts and Georgia provide typography. Screenshots in docs are captured from the actual game by Playwright, not concept images.
